# 02-01: Terrain Observation Types + Builder + Tensor Pipeline

## Goal
Wire terrain footprints from `BattleView.terrain` through the observation pipeline
so they appear as a terrain tensor in `observation_to_tensor` / `observations_to_tensor_batch`.

## Tasks

1. **`WargameTerrainObservation`** — new dataclass in `types/terrain_observation.py`:
   footprint as 4-float normalized corner array, `size` property.
2. **`WargameEnvObservation`** — add `terrain: list[WargameTerrainObservation]`
   (default empty), `size_terrain`, `n_terrain` properties; include terrain in `size`.
3. **Export** — add `WargameTerrainObservation` to `types/__init__.py`.
4. **`observation_builder.py`** — `_terrain_to_obs(view)` normalizes footprint
   corners to [-1, 1] using board half-dims; wire into `build_observation`.
5. **`model/common/observation.py`** — `TERRAIN_FEATURE_DIM = 4`; extend
   `_observation_to_numpy` to 6-tuple adding terrain `(n_terrain, 4)`;
   `observation_to_tensor` returns 6 tensors (terrain at index 4, mask at 5);
   `observations_to_tensor_batch` likewise.
6. **`dataset.py`** — update `experience_list_to_batch`: `state_tensors[:5]`,
   `next_state_masks` at index 5.
7. **PPO lightning** — update `range(5)` → `range(6)` for rollout feature slots.
