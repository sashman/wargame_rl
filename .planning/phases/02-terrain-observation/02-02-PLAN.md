# 02-02: Network Terrain Embedding + Backward-Compat Tests

## Goal
Add terrain embedding to TransformerNetwork (and terrain inclusion to MLPNetwork)
so both can process terrain tokens, with backward compatibility when no terrain
is configured.

## Tasks

1. **TransformerNetwork** — add `terrain_size` constructor arg; create
   `terrain_embedding: nn.Linear | None` (None when terrain_size == 0);
   `_embed_terrain()` method; `encode_state()` reads terrain at xs[4],
   mask at xs[5], appends terrain tokens after opponents; update
   `share_backbone_with()` and `from_env()`.
2. **MLPNetwork** — `forward` uses `xs[:5]` (includes terrain); `from_env`
   includes terrain tensor in obs_size.
3. **Tests** — `test_terrain_observation.py`:
   - TERR-08: token count, normalized geometry, tensor shape, batch shape,
     static across steps
   - TERR-09: no-terrain zero rows, empty obs.terrain, shape unchanged
   - Network integration: terrain_embedding None/present, forward pass
     with/without terrain (Transformer policy/value + MLP), player token
     positions unchanged
